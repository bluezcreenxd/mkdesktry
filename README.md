## mkdesktry
makes desktop entries for appimages
+ automatically extracts the icon for you
has 2 modes

syntax: uses flags

options:
  -n name        display name  (default: guessed from filename)
  -c comment     short description
  -g categories  e.g. "Network;Chat;"  (default: Utility;)
  -i icon        path or theme name    (default: auto-extract)
  -t             run in terminal
